# Frontend Senior+ Roadmap

Интерактивное приложение для изучения и повторения тем frontend-разработки.

## Запуск

```bash
# Распаковать
tar xzf senior-roadmap.tar.gz
cd senior-roadmap

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Откройте http://localhost:5173

## Структура

- `src/data/` — все темы и контент по разделам
- `src/App.jsx` — главный компонент
- `src/App.css` — стили
